# 💪 NicoGym

Aplicación PWA desarrollada para gestionar mis entrenamientos, progreso físico y objetivos.

## Funciones

- Rutinas
- Registro de peso
- Medidas corporales
- Fotos comparativas
- Récords
- Agenda

## Uso

Sirve la carpeta desde un origen HTTPS para instalar la app y habilitar el modo sin conexión. El shell y los recursos locales se guardan en caché; imágenes remotas y fuentes solo estarán disponibles offline si ya se descargaron antes.

El historial se guarda en el almacenamiento local del navegador y las fotos en IndexedDB. Usa Exportar periódicamente para conservar una copia fuera del dispositivo.

## Tecnologías

- HTML
- CSS
- JavaScript
- PWA (Web App Manifest y service worker)
- LocalStorage
